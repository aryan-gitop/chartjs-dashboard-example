# 📊 Chart.js Data Visualization

A simple and interactive **business analytics dashboard** created as a practice project using **Chart.js**.

The project demonstrates how different chart types can be used to visualize business data such as revenue, expenses, profit, sales, and regional performance.

## ✨ Features

* 📈 Revenue vs Expenses vs Profit — Line Chart
* 📊 Monthly Sales — Bar Chart
* 🥧 Profit Distribution — Pie Chart
* 🌍 Regional Sales by Country — Bar Chart
* 📱 Responsive dashboard layout
* 🎨 Clean and minimal UI
* 💬 Interactive Chart.js tooltips and legends

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Chart.js
* Google Fonts

## 📁 Project Structure

```text
chartjs-data-visualization/
│
├── index.html
├── charts.css
└── README.md
```

## 🚀 How to Run

1. Clone or download this repository.
2. Open `index.html` in your browser.
3. Explore the interactive charts.

No additional installation is required.

## 📌 Purpose

This project was created to practice **data visualization with Chart.js** and understand how different chart types can be implemented using HTML, CSS, and JavaScript.

> **Note:** The data used in this project is sample/illustrative data and is intended for demonstration purposes only.
